# Kirchhoff’s Junction Rule
- A junction is where 3 or more wires meet in a junction. Since we know current cannot accumulate at a point, all the current must flow into the 3 pathways. The rule is as follows…
$$\sum I_{in}=\sum I_{out}$$
- The sum of current entering a junction equals the sum of current leaving the junction. 
	- This is simply charge conservation, all the current entering a junction must equal all the current leaving a junction. This can also be rewritten as…
$$\sum I_{in} \space-\space \sum I_{out}=\sum I=0$$

- In combination with Kirchhoff’s Loop Rule, we can find a system of equations to solve for the current through each component.
